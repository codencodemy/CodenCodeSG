Data Analyst

Turn raw data into decisions — the most accessible entry point into Singapore's data field.

1
codencode.sg → Python Fundamentals

Learn Python & data basics

Variables, data structures, pandas basics, reading/cleaning real datasets.

Not yet paid — skills stage
2

External: SQL + BI tooling

Add SQL, Excel/Power BI or Tableau, and a portfolio dashboard project. Consider Google Data Analytics or SSG-funded SQL/BI short courses.

Not yet paid — skills stage
3

Entry-level Data Analyst

0–2 years experience. First role — usually in a reporting, ops-analytics or BI team.

S$36,000–54,000 / yr

Data Scientist

Beyond reporting — build predictive models and run experiments that shape product decisions.

1
codencode.sg → Python Fundamentals + Machine Learning Fundamentals

Learn Python, stats & ML basics

Pandas, scikit-learn, regression/classification, model evaluation on real datasets.

Not yet paid — skills stage
2

External: statistics & a capstone

Deepen statistics/experimentation knowledge and ship an end-to-end capstone (data → model → report) for your portfolio.

Not yet paid — skills stage
3

Entry-level Data Scientist

0–3 years experience, applying ML to a real business problem under senior guidance.

S$60,000–85,000 / yr
Hires in Singapore: GrabSea Group (Shopee)GICTemasekGovTech

ML Engineer

Take models from notebook to production — the engineering-heavy sibling of data science.

1
codencode.sg → Python Fundamentals + Machine Learning Fundamentals

Learn Python & applied ML

Solid Python fundamentals plus scikit-learn model-building — the base every ML engineer needs.

Not yet paid — skills stage
2

External: MLOps & deployment

Learn Docker, APIs (FastAPI/Flask), and a cloud platform (AWS/GCP) to deploy models as services.

Not yet paid — skills stage
3

Junior ML Engineer

Ships and maintains ML models in production systems, usually alongside a senior ML/data team.

S$70,000–100,000 / yr
Hires in Singapore: GrabSea Group (Shopee)RazerGICTemasek

Automation Engineer / RPA Developer

Automate repetitive business processes — high demand in SG banks, insurers and shared-services teams.

1
codencode.sg → Python Fundamentals + Vibe Coding

Learn Python scripting & AI-assisted building

Automate files, spreadsheets and web tasks in Python; use AI coding assistants to prototype automations fast.

Not yet paid — skills stage
2

External: an RPA platform

Get certified on a named RPA tool (e.g. UiPath, Power Automate) — most SG job ads name a specific platform.

Not yet paid — skills stage
3

Junior RPA / Automation Engineer

Builds and maintains bots/scripts that automate manual back-office workflows.

S$45,000–65,000 / yr
Hires in Singapore: DBSOCBCUOBSingtel

Cybersecurity Analyst / Engineer

Defend systems and data — one of Singapore's most acute tech skill shortages.

1
codencode.sg → Cybersecurity Fundamentals

Learn network security & ethical hacking basics

Core networking, common attack types, and incident-response fundamentals, mapped to CSA guidance.

Not yet paid — skills stage
2

External: an industry certification

Add CompTIA Security+ (or equivalent) and hands-on lab practice (e.g. TryHackMe) to strengthen your résumé.

Not yet paid — skills stage
3

Junior Cybersecurity Analyst

0–2 years experience — SOC monitoring, vulnerability triage, and security operations support.

S$48,000–60,000 / yr
