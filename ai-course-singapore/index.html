Vibe Coding — build apps with AI tools

A 4-week online course on building real apps with AI-assisted development tools such as Cursor, GitHub Copilot and Claude. No deep computer-science background is needed, and you aim to ship something in week one. It is the gentlest way into coding if you want results fast.

Machine Learning Fundamentals

A 10-week online course for learners who already have some Python. You train real machine learning models, learn the maths that matters, and build projects you can show employers. New to Python? Start with Python Fundamentals first.

AI for ___ workshops (in person)

Half-day, in-person sessions in Singapore (venue details via WhatsApp), 4 hours each, for teams and individuals: AI for Workplace, AI for Marketing, AI for Event Management, AI for HR, AI for Accounting. These are fixed-format, one-off workshops — not enrolled multi-week courses.
